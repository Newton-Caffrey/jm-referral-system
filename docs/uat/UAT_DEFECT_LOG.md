## Severity definitions

| Severity | Meaning |
| --- | --- |
| Critical | Data exposure, data corruption, total workflow failure, security bypass |
| High | Core workflow blocked with no practical workaround |
| Medium | Workflow issue with workaround |
| Low | Cosmetic, wording, or minor usability |
