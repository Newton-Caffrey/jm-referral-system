# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| &lt; 1.0 | No |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Email: `newtontavengwa@gmail.com`  
(Replace with the production security contact before any public distribution.)

Include plugin version, WordPress/PHP versions, reproduction steps, and impact.

We aim to acknowledge reports within **5 business days**, assess severity, and coordinate disclosure after a fix or mitigation is available.

Full operational security notes: `docs/SECURITY.md`.
